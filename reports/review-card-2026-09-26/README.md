# Review card kit — 2026-09-26

- `review-card.pdf` — the print-ready card, A6 portrait (105mm x 148mm), one page.
- `review-card.html` — source for the PDF, self-contained (no external fonts/network).
- `review-card-preview.png` — quick visual check of the layout.
- `qr-review.svg` / `qr-review.png` — the QR code alone, encodes `https://hairbymelissa.co.nz/review/`, error correction level M.
- `thank-you-text.md` — SMS/text template to send clients after an appointment.

## Printing
- Print `review-card.pdf` at actual size on A6 stock, or place 4 copies on an A4 sheet ("N-up") and print at **100% scale — do not use "fit to page" or "shrink to fit"**, or the QR will scale down and become unreliable.
- Use a decent print resolution (300dpi+) so the QR stays crisp; avoid photocopying a photocopy.
